
# Online Resume Builder 📄

## 📌 Project Description

The Online Resume Builder is a web-based application designed to help users create professional resumes easily and quickly. The application allows users to enter personal information, educational qualifications, skills, career objectives, and project details.

The entered information is dynamically displayed in a resume preview using HTML, CSS, and JavaScript. Users can generate their resume and save it as a PDF. This project provides a simple, user-friendly interface for students and job seekers.

## 🎯 Objectives

- To create professional resumes easily.
- To reduce the time required to prepare resumes.
- To provide a simple and user-friendly interface.
- To generate resumes dynamically.
- To allow users to save their resumes as PDF files.

## ✨ Features

- Personal information input

- Education details
- Skills section

Open the index.html file in your web browser.

## 🚀 How to Use

1. Open the Online Resume Builder website.
2. Enter your full name and contact details.
3. Add your career objective.
4. Enter education and skills.
5. Add project details.
6. Click the Generate Resume button.
7. Preview your resume.
8. Save your resume as a PDF.
